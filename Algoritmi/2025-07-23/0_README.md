# CONTENUTO DI QUESTA CARTELLA

- i file votiAlgoritmi*.txt contengono, in forma succinta o più estesa, le tabelle coi voti (e i punteggi) per questo appello
- per ciascuno di voi che abbia sottomesso soluzioni in sede di esame, il folder your_submissions.cyphered contiene il suo archivio personale (VR??????.zip) dei codici sottomessi al server via `rtal` (tramite l'argomento `-a source=...` di `rtal`).


> [!NOTE]
> questi archivi sono privati e cifrati per ragioni di privacy, ma con la tua password personale puoi decifrare il tuo archivio quando lo espandi/decomprimi (se con `unzip` utilizza l'argomento `-P`). 

[!TIP]
> Per ottenere la tua password personale invoca:
> > rtal -s wss://ta.di.univr.it/algo connect password

## Impiego dei tuoi codici

Decompressa la tua cartella con tutti i codici sottomessi (nelle varie versioni), puoi non solo visionare le tue soluzioni ma anche testarle e completarle/rivederle sottoponendole al server per gli homework:

> rtal -s wss://ta.di.univr.it/algo list

Potrai così prendere le tue verifiche e/o completare la tua esperienza d'esame.
Questo ti consente inoltre di recuperare dei punti bonus se non avevi già saturato questa voce (di max 5 punti voto).
